Umidigi follows the [standard unlock procedure](../../misc/generic-unlock.md) for their MediaTek devices. Unisoc devices cannot be unlocked, this is *not* Umidigi's fault, Unisoc does not allow unlocking.

## Kernel sources
Umidigi initially **released the kernel source code for some of their early phones** (Umidigi Bison Pro and Umidigi F2) [on GitHub](https://github.com/UMIDIGI-Official?tab=repositories), although these source codes were broken, did not contain all modules, lacked proper build instructions, and all issues remained unresolved.

Since then, **they have never released any kernel source code or respond to requests by claiming they cannot provide it**, thereby violating the terms GPL license. The lack of kernel source code severely limits the creation of custom ROMs, and can also at times make it more difficult to root or run GSIs.
